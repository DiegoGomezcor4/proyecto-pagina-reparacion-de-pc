# 💻 Geeksy — Tech & Web Studio

Sitio web oficial de **Geeksy** ([geeksy.com.ar](https://geeksy.com.ar/)), estudio tecnológico especializado en **Servicio Técnico y Reparación de PC/Notebooks** y **Diseño y Desarrollo de Páginas Web** en Corrientes, Argentina.

---

## ✨ Características Principales

- **Diseño "Modern Tech & Web Studio"**: Interfaz oscura (*dark mode*) con efecto *glassmorphism*, grilla tecnológica sutil y acentos luminosos diferenciados por unidad de negocio.
- **Doble Propuesta de Valor**:
  - 🔧 **Área Hardware & Sistemas (`#reparacion-pc`)**: Reparación de hardware, optimización extrema con discos SSD, limpieza física/térmica y redes WiFi.
  - 🚀 **Área Estudio Digital (`#diseno-web`)**: Creación de Landing Pages de alta conversión, Catálogos con pedidos por WhatsApp y Sitios Web Institucionales con SEO local.
- **Diagnóstico Rápido Interactivo**: Botones de síntomas frecuentes (*"Está muy lenta"*, *"No enciende"*, *"Calienta mucho"*, etc.) que abren WhatsApp con el mensaje pre-redactado para acelerar consultas.
- **Mockups Visuales en CSS Puro**: Vistas previas livianas de los 3 modelos de sitios web sin sobrecargar la página con imágenes pesadas.
- **Sección de Packs Estrella (`#packs`)**: Paquetes listos para contratar (*Pack Service & Limpieza Full*, *Pack Reviví tu PC con SSD* y *Pack Tu Primera Página Web*).
- **Formulario de Contacto Inteligente**: Integrado con **Formspree**, con selector de servicio que adapta automáticamente el mensaje de consulta.
- **SEO Local & Rendimiento**:
  - Metadatos Open Graph, Twitter Cards y datos estructurados `Schema.org (LocalBusiness)`.
  - Archivos `sitemap.xml` y `robots.txt` configurados.
  - Logo optimizado (`logo.png` de ~42 KB) para carga instantánea en dispositivos móviles.

## 🚀 Uso Local y Despliegue

1. **Clonar el repositorio:**
   ```bash
   git clone <url-del-repositorio>
   cd "pagina reparacion de pc - Geeksy"
   ```

2. **Ejecutar localmente:**
   Al ser un sitio estático (HTML5, CSS3 y JavaScript Vanilla), puedes abrir directamente el archivo `index.html` en cualquier navegador o levantar un servidor local:
   ```bash
   python3 -m http.server 8000
   ```
   Luego abre `http://localhost:8000` en tu navegador.
